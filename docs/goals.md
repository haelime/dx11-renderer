## 1. 최종 목표 한 줄

> **C++/Direct3D 11로 처음부터 직접 만든 작은 "아레나" 데모.**
> 렌더러 위에서 캐릭터가 적을 치면 손맛(히트스톱·셰이크·파티클)이 나고, 에셋은 백그라운드에서 로딩되고, 클라이언트 두 개를 켜면 서로가 보인다.
> 모든 코드는 내가 쳤고, 모든 부분을 보지 않고 설명할 수 있다.

기술 데모로 끝내지 않고 **플레이 가능한 장면** 하나로 키운다. 렌더러는 엔지니어링을, 손맛은 내 강점(심미안·연출)을 보여준다.

## 4. 단계별 목표와 할 일

각 단계는 **결과물(보여줄 것)** + **완료 기준(말할 수 있어야 하는 것)** 이 둘 다 돼야 끝난다.

### 0단계 · 기초 → 건너뜀 (2026-10-12 결정)

렌더러를 바로 시작한다. 벤치마크(배열 vs 연결 리스트, AoS vs SoA, memcpy 대역폭)와 컴퓨터 구조 이론은 learning.md "나중에"로 옮겼다. 렌더러에 필요한 기초(구조체 정렬, CPU→GPU 업로드 등)는 1단계에서 필요해지는 시점에 공부한다.

## 5. 범위 규칙 (내 약점: 완성 전에 넓히기)

1. **손맛 작업은 1단계(10주차) 아레나 최소 버전이 돌아간 뒤에만** 시작한다.
2. 단계를 시작할 때 "**잘라도 되는 것**"을 먼저 적는다. 2주 이상 밀리면 위에서부터 자른다.
   - 기본 자를 것 목록: 그림자 맵 → 디퍼드 셰이딩 → PBR → 디퍼드 컨텍스트 → 공격 이벤트 동기화(위치 동기화만 남김)
   - 절대 안 자르는 것: Win32·DX11 파이프라인·카메라·조명, 스레드 안전 큐·비동기 로딩, TCP 패킷 처리·위치 동기화, IOCP 기본
3. 새로 하고 싶은 건 learning.md "나중에"에 적고 돌아온다. (ImGui, DX12, 사운드, 애니메이션, 에디터 등)
4. 아트는 단순 도형 + CC0 에셋. 출처는 README에 적는다. AI 생성 아트는 이 프로젝트에 넣지 않는다 (이 프로젝트는 "전부 내가 했다"가 핵심).
