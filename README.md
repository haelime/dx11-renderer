# dx11-renderer

C++와 Direct3D 11로 처음부터 직접 만드는 작은 3D 렌더러. 단계적으로 멀티스레드 에셋 로딩과 TCP 네트워크 동기화까지 확장한다.

**최종 목표**: 이 렌더러 위에서 돌아가는 작은 아레나 데모. 적을 치면 손맛(히트스톱·셰이크·파티클)이 나고, 에셋은 백그라운드에서 로딩되고, 클라이언트 두 개가 서로 보인다. 목표·단계별 할 일·범위 규칙: [docs/goals.md](docs/goals.md)

## 이 프로젝트의 규칙

1. **코드는 내 손으로 친다.** AI는 개념 설명과 질문 상대로만 쓴다. 예시 코드를 보면 덮고 다시 쓴다.
2. **지금 단계를 보지 않고 설명할 수 있을 때만 다음 단계로 간다.** (각 단계의 "완료 기준" 참고)
3. **커밋은 실제로 한 날, 한 만큼만.** 작게, 자주.
4. 막히면 막힌 지점을 `docs/devlog.md`에 적는다. 막힌 기록이 면접에서 가장 좋은 이야기가 된다.
5. 범위를 늘리고 싶을 때는 `docs/learning.md`의 "나중에" 목록에 적고, 지금 단계를 먼저 끝낸다.

## 단계 (6개월, 2026-10-12 ~ 2027-04-11)

| 페이즈 | 주 | 내용 | 상태 |
|---|---|---|---|
| 0 | 1~3 | 기초: C++ 메모리 모델, 컴퓨터 구조(CPU~PCI-e~GPU), OS, Win32 창 | 시작 전 |
| 1 | 4~10 | 그래픽스 코어: 파이프라인, 버퍼, 카메라, 메시·텍스처, 조명, 그림자 → 아레나 최소 버전 | 시작 전 |
| 2 | 11~14 | 그래픽스 심화 + 손맛: 인스턴싱 파티클, HDR·블룸 히트 플래시, 히트스톱·셰이크, GPU 시간 측정 | 시작 전 |
| 3 | 15~18 | 멀티스레드: 스레드 풀, 잡 시스템, 비동기 로딩, 디퍼드 컨텍스트 | 시작 전 |
